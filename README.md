# [YMUtl](https://ymutl.leftcontroller.com/)
YMM4とAviUtl/AviUtl2の情報共有をするSNS
> [!WARNING]
> ここにソースコードはありません。
> 
> ソースコードはprivateリポジトリで厳重にアクセスを制限しています。

## YMUtlとは？
YMUtlとは、YMM4・AviUtl/AviUtl2ユーザーが交流する非公式のSNSです。

制作者：左コントローラー

協力者：[ゆっくりなぢ](https://github.com/yukkurinadi)

## 何ができる？
主な機能は以下の通りです。
1. 2chのようなスレッド機能
2. YMM4・AviUtl/AviUtl2の情報が随時更新される百科事典
3. プラグイン投稿
4. Xのようなつぶやき機能
5. 知恵袋のようなQ&A機能
6. リアルタイムでユーザーが交流できるオープンチャット

> [!IMPORTANT]
> このSNSは現在開発中です。
> 
> 機能が実装しきれていない部分や、バグなどが多数あります。予めご了承ください。
